# Mix & Match Calories

Mix your favorite foods into your perfect day – calories and protein are calculated automatically.

- Web-App (HTML, CSS, JavaScript), keine Installation nötig
- Deine Daten bleiben in deinem eigenen Browser (localStorage) – nichts wird an einen Server geschickt
- Nährwerte: USDA FoodData Central und [Open Food Facts](https://openfoodfacts.org) (ODbL)
- Barcode-Scanner: eingebauter BarcodeDetector bzw. [ZXing](https://github.com/zxing-js/library) (Apache-2.0)
